Git est un système de gestion de versions distribué (DVCS) conçu pour suivre les modifications apportées aux fichiers et faciliter le travail collaboratif sur des projets. Créé en 2005 par Linus Torvalds, le créateur du noyau Linux, Git est aujourd'hui l'outil de contrôle de version le plus utilisé dans le monde, aussi bien pour des projets open source que commerciaux.

Contrairement aux systèmes centralisés comme SVN, Git permet à chaque développeur de disposer d'une copie complète du dépôt, incluant tout l'historique des modifications. Cela offre une grande flexibilité, notamment pour travailler hors ligne ou gérer des branches indépendantes.
